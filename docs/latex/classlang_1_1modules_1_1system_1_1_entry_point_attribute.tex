\doxysubsection{Detailed Description}
Entry point attribute. 

Marks the function it\textquotesingle{}s applied to as the program entry point. The program entry point is the default function that\textquotesingle{}s called when calling \doxylink{structlang_1_1_interpret_context_aa4d78366ed858ba69fa6a47c666049b2}{Interpret\+Context\+::run()} Only one Entry\+Point attribute can be used in a program.
